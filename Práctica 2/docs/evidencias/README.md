## Cómo tomar una captura faltante

### Importación

No vuelvas a presionar **Terminar** si la tabla ya contiene datos, pues eso duplicaría
la carga y produciría errores de llave primaria. Abre el asistente, selecciona el
Excel y la hoja correcta, toma la captura de la vista previa y luego pulsa
**Cancelar**.

### Resultado

Abre la tabla, selecciona la pestaña **Datos** y actualiza la cuadrícula. Procura que
se observen el nombre de la tabla, los encabezados y todas las filas. No es necesario
mostrar el panel de mensajes inferior si contiene intentos o errores anteriores.
