\section{Introducción y objetivo}

La presente práctica implementa el modelo físico del Sistema de Gestión de
Prácticas Profesionales Supervisadas (EPS) en Oracle Database. El trabajo comprende
la creación de la estructura relacional, la carga jerárquica de datos desde un libro
de Excel y la elaboración de cinco reportes mediante sentencias DQL compatibles con
Oracle.

El objetivo es poblar correctamente las 16 tablas del modelo respetando sus llaves
primarias y foráneas, y transformar los datos almacenados en información útil mediante
uniones explícitas, agrupaciones y funciones de agregación.

\section{Procedimiento de importación}

El siguiente procedimiento se aplicó a cada tabla, respetando estrictamente el orden
anterior:

\begin{enumerate}
  \item Localizar la tabla en \textbf{Conexiones $>$ Tablas} dentro de
        \texttt{BD1 Práctica 2}.
  \item Abrir el menú contextual de la tabla y seleccionar \textbf{Import Data}.
  \item Elegir el archivo \texttt{Dataset\_Practica2.xlsx}.
  \item Seleccionar la hoja con el mismo nombre de la tabla y verificar la vista previa.
  \item Indicar que la primera fila contiene los encabezados y usar el método
        \textbf{Insertar}.
  \item Comprobar que cada encabezado del Excel se encuentre asociado con la columna
        Oracle del mismo nombre.
  \item Revisar el resumen y finalizar la importación.
  \item Abrir la pestaña \textbf{Datos}, actualizarla y comparar la cantidad de filas
        con el valor esperado.
  \item Confirmar la transacción cuando corresponda mediante \texttt{COMMIT}.
\end{enumerate}

Antes de continuar con la tabla siguiente se verificó que la importación actual
hubiera terminado correctamente. Esto evita propagar errores y facilita identificar
la tabla que origina una posible violación de integridad.

\section{Conclusiones}

\begin{enumerate}
  \item El orden de carga permitió mantener la integridad referencial y evitó insertar
        llaves foráneas antes de sus registros padre.
  \item El asistente de Oracle SQL Developer facilitó la asociación controlada de las
        columnas del libro de Excel con la estructura física de cada tabla.
  \item Las uniones explícitas permitieron reunir información normalizada distribuida
        entre estudiantes, empresas, plazas, colocaciones, contactos y catálogos.
  \item Las funciones \texttt{COUNT} y \texttt{SUM}, junto con \texttt{GROUP BY} y
        \texttt{HAVING}, permitieron construir los reportes estadísticos y de auditoría
        solicitados.
  \item Las evidencias obtenidas confirman la carga completa del conjunto de datos y la
        ejecución satisfactoria de las cinco consultas.
\end{enumerate}
